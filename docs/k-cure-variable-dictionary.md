## 1. 교체 대상 = 현재 합성 가정 목록

`configs/dynamic_poc_v0_2.json`에서 데이터가 아니라 **가정**으로 채워진 블록:

| 합성 블록 | 현재 값(예) | 실제로 필요한 추정치 |
|---|---|---|
| `response_probabilities` | intensified major 0.35 | 선행치료 강도별 major/partial/none 반응 확률 |
| `tumor_size_multipliers` | major → ×0.50 | 반응 등급별 종양 크기 변화율 |
| `acute_toxicity_probabilities` | 강화항암 0.30 | 치료·강도별 급성 독성 발생률 |
| `treatment_burden` | 강화항암 0.20 | 치료 부담 가중치(선호 연구 또는 utility) |
| `hazard_multipliers.response` | major death ×0.95 | 반응 등급이 사망·재발 위험에 미치는 효과 |
| `hazard_multipliers.chemo/endocrine/radiation` | intensified death ×0.95 | 치료 강도의 위험 조정 효과 |
| `hazard_multipliers.death_after_recurrence` | ×2.00 | 재발 후 사망위험 배수 |
| `reward.*` | 독성 페널티 0.15 | utility 가중치(환자 선호·QALY) |

**민감도 분석(`reports/sensitivity-v0.3/`) 결과 가장 영향이 큰 블록부터 우선 교체**한다.

## 2. 블록별 추정 계획과 필요한 K-CURE 변수

### 2.1 선행치료 반응 확률 (`response_probabilities`)

- 추정치: P(반응등급 | 치료강도, 아형) — 예 pCR/부분/무반응 비율.
- 필요한 변수: 선행치료 여부·약제·cycle, 반응 평가(영상 RECIST 또는 병리 pCR),
  평가일, 아형. `〔코드북 확인: 항암 투여 테이블, 반응평가 테이블〕`
- 방법: 아형·강도 층별 빈도 추정 + 축소(shrinkage).

### 2.2 종양 크기 변화 (`tumor_size_multipliers`)

- 추정치: 반응 등급별 (치료후 크기 / 치료전 크기) 중앙값.
- 필요한 변수: 치료 전·후 종양 크기(영상/병리), 측정일. `〔코드북 확인: 영상/병리 테이블〕`

### 2.3 급성 독성 (`acute_toxicity_probabilities`)

- 추정치: P(급성 이상반응 | 치료·강도) — 등급 기준 사전 확정 필요.
- 필요한 변수: 이상반응 코드(CTCAE 등급), 입원, 치료 중단·감량, 발생일.
  `〔코드북 확인: 이상반응/입원 테이블〕`

### 2.4 위험 조정 효과 (`hazard_multipliers`)

- 추정치: 반응·치료강도가 OS/RFS hazard에 미치는 효과.
- **주의**: 이 값은 §target-trial의 **인과추정 대상**이다. 단순 층별 비교가 아니라
  IPW/g-방법으로 교란 보정한 추정치를 써야 한다.
- 필요한 변수: 치료 순서·강도·용량, 반응, 재발일, 사망일, 마지막 추적일, 교란
  (동반질환·수행상태·병원·연도). `〔코드북 확인: 치료·추적·동반질환 테이블〕`

### 2.5 재발 후 사망위험 (`death_after_recurrence`)

- 추정치: 재발을 시간의존 변수로 둔 사망 hazard 비.
- 필요한 변수: 재발일, 사망일. 시간의존 Cox 또는 다상태 모형.

### 2.6 utility 가중치 (`reward.*`)

- 추정치: 데이터가 아니라 **가치판단**. 문헌 QALY 또는 환자선호 연구에서 가져오고
  출처를 사전등록. 임상 자문 필수.

## 3. K-CURE 데이터 요청 체크리스트

교체를 시작하려면 아래 범주가 필요하다(정확한 변수명은 코드북에서 확정):

- [ ] 인구학: 진단 나이, 성별, 폐경
- [ ] 종양: 병기(AJCC 판본·진단시점), 종양 크기(치료 전/후), 림프절, 등급, ER/PR/HER2, Ki-67
- [ ] 시간 기준: 진단일, 치료 시작·종료일, 반응 평가일, 재발일, 사망일, 마지막 추적일
- [ ] 치료: 수술 종류·범위·일자, 항암 약제·용량·cycle, 내분비 약제·기간, 방사선 범위·선량
- [ ] 반응·독성: 반응 평가(영상/병리), 이상반응 코드·등급, 입원, 중단/감량
- [ ] 교란: 동반질환, 수행상태(ECOG), 병원, 진단연도, 사회경제 지표(가능 시)

## 4. 교체 순서 (권장)

1. 민감도 분석에서 **영향 큰 블록** 확인 → 우선순위 결정.
2. K-CURE 코드북으로 위 §3 변수의 원천 테이블·코드 확정(이 문서의 `〔코드북 확인〕` 채우기).
3. `analysis/dynamic/`의 `PatientProfile`로 변환하는 `k_cure_adapter.py` 작성.
4. 각 합성 블록을 §2의 추정치로 하나씩 교체하고, 교체 전후 결과 변화를 리포트.
5. 위험 조정 효과(§2.4)는 target-trial 인과 분석으로 별도 추정.
6. positivity·결측·병원별 차이 진단 후 외부검증.

## 5. 바뀌지 않는 부분 (재확인)

동적 상태·전이 인터페이스, action mask 구조, chance-aware UCT 탐색기, episode 평가·
시드 재현 체계, report 산출 방식은 데이터셋이 바뀌어도 그대로 재사용한다
(3층 분리 설계). 교체되는 것은 **§2의 숫자(위험·전이·독성·utility)뿐**이다.
