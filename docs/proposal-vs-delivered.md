# 제안서 대비 실제 산출물

제안서(2026-04)와 지금(2026-08)을 나란히 놓은 표입니다. **범위가 줄어든 항목이 많습니다.**
발표에서 제안서를 들고 오는 질문이 반드시 나오므로, 숨기지 않고 먼저 정리해 둡니다.

핵심은 이것입니다. **범위를 줄인 대신 "검증"의 깊이를 얻었습니다.** 2026-05-26 킥오프에서
연구 frame을 "가이드라인 검증 PoC"로 좁힌 결정이 이후 모든 축소의 근거입니다.

## 축소하거나 하지 않은 것

| 제안서 | 실제 | 왜 |
|---|---|---|
| **DQN 에이전트 + MCTS 결합** | MCTS(UCT)만 | 신경망 학습은 데이터 규모·기간이 안 맞았다. 순차 계획의 핵심 질문은 MCTS만으로 답할 수 있다 |
| **오픈소스 ODE 시뮬레이터 활용** | Cox 보상모형 + 명시적 합성 전이로 직접 구축 | 유방암 다단계 치료를 다루는 검증된 공개 ODE 환경을 찾지 못했다. 대신 **모든 가정을 설정 파일로 드러내는** 방식을 택했고, 그 덕에 민감도 분석이 가능해졌다 |
| **TCGA + METABRIC 약 3,600명** | METABRIC 단독 (분석가능 1,980명) | 두 코호트의 임상마커 정의가 달라 병합 시 변수 손실이 크다. 단일 코호트로 일관성을 택했다 |
| **가상 환자 1,000명** | 보류 테스트셋 390명, 정책 비교는 12~40명 | 정책 비교는 환자 수보다 **시드·가정 반복**이 병목이었다. 같은 계산으로 12명×20시드를 도는 것이 1,000명×1시드보다 정보가 많다 |
| **약물 종류·용량·투여 간격·휴약기** | 항암 3단계(none/standard/intensified) 범주형 | METABRIC에 용량·투여 시점 정보가 없다. 없는 데이터를 모델링하면 가정이 결과를 지배한다 |
| **Ki-67** | PAM50 LumA/LumB로 대용 | METABRIC에 Ki-67 측정값이 없다 |
| **표적치료·BRCA1/2 별도 행동** | 미반영 | 데이터 부재. HER2 상태는 State에 포함돼 있다 |
| **클라우드 GPU 환경** | 로컬 CPU 실행 | MCTS는 GPU가 필요 없다. 최대 실험(v0.4)도 로컬에서 약 40분이면 끝난다 |
| **임상 전문의 자문** | 미확보 (진행 중) | 현재까지의 산출물은 전부 방법론 검증 단계다. 임상 해석이 필요한 시점에 확보하는 것이 목표 |
| **학회 포스터·논문 초안** | 미착수 | 9개월 일정의 후반 작업 |

## 제안서에 없었는데 한 것

제안서는 "만들고 비교한다"까지였습니다. 실제로는 **비교의 신뢰도를 검증하는 작업**이
연구의 절반 이상을 차지했습니다.

| 산출물 | 내용 |
|---|---|
| **다중 시드 강건성 (v0.3)** | 단일 시드 결과가 낙관적 끝단이었음을 확인. 20시드 CI와 결정 안정성 측정 |
| **합성 가정 민감도 (v0.3)** | 결론을 가장 크게 흔드는 것이 임상 효과가 아니라 **보상 가중치**임을 규명 |
| **탐색 예산 스케일링 진단 (v0.4)** | 결정 불안정성의 원인을 탐색 부족 / 진짜 동률로 분리. **256은 해상도 미달**이었음을 발견 |
| **MCTS·MDP 개념 감사 (v0.5)** | 환경이 선행치료에 주던 **미선언 이득**을 발견·수정 |
| **Target trial 프로토콜** | 관찰 연관성을 인과추정으로 바꾸기 위한 명세 (Hernán-Robins) |
| **K-CURE 변수 사전** | 합성 가정을 실제 추정치로 교체하기 위한 요청 명세 |
| **재현 인프라** | 실행마다 입력 SHA-256·시드·커밋을 남기는 매니페스트, 단위 테스트 45종 |

## 이 축소를 어떻게 설명할 것인가

발표에서 쓸 한 문장:

> 제안서는 "AI로 더 나은 치료 전략을 찾는다"였지만, 9개월 안에 **믿을 수 있게** 답할 수 있는
> 질문으로 좁혔습니다. 그 결과 우리가 얻은 것은 "MCTS가 이겼다"가 아니라
> **"이 비교를 어디까지 믿을 수 있는지"에 대한 정량적 답**입니다.

세 번의 검증에서 매번 우리 자신의 결과를 깎는 발견이 나왔다는 점이 이 연구의 성격을
보여줍니다 — 단일 시드는 낙관적 끝단이었고, 탐색 예산은 해상도에 미달했고, 환경은 한쪽
편을 들고 있었습니다.

## 아직 제안서 약속 중 살아 있는 것

- **가이드라인의 개선 가능 지점 도출** — 동률 지점(호르몬치료·방사선)이 후보다.
  단, utility 사전등록 없이는 주장할 수 없다.
- **타 고형암 확장 가능한 모듈형 구조** — `analysis/dynamic/schema.py`가 데이터셋 중립
  스키마이고 K-CURE 어댑터를 따로 두는 설계로 유지되고 있다.
- **논문·학회 발표** — 후반 일정.
