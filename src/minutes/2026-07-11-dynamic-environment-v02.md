# 동적 환경 v0.2 — 상태가 실제로 변하기 시작했다

> **아주 쉽게 말하면**: v0.1은 메뉴 16개 중 하나를 고르는 문제였다. v0.2는
> 음식을 먹어 본 결과가 좋았는지, 부작용이 있었는지에 따라 다음 주문이 달라지는
> 문제다.

이번 작업의 목적은 “선택지를 많이 보이게 만들기”가 아니다. **앞 치료의 결과가
다음 선택지를 바꾸게 만드는 것**이다.

---

## 정적 환경과 동적 환경의 차이

### 이전 v0.1

```text
처음 환자정보
  -> 수술 선택
  -> 항암 선택
  -> 호르몬 선택
  -> 방사선 선택
  -> 최종 점수
```

치료를 골라도 종양 크기나 환자 상태는 변하지 않았다. 그래서 정확히는 “치료
조합 검색기”에 가까웠다.

### 새로운 v0.2

```text
처음 환자정보
  -> 치료 순서 선택
  -> 치료 반응 발생
  -> 종양 크기·독성 상태 변경
  -> 바뀐 상태에서 다음 치료 선택
  -> 매년 무사건 / 재발 / 사망 발생
```

![동적 환경 전체 흐름](/figures/fig14_dynamic_environment_flow.png)

예를 들어 처음 종양이 40mm인 환자는 바로 BCS를 선택할 수 없다. 그런데
선행치료 후 큰 반응이 나와 20mm가 되면 BCS가 새 선택지로 열린다. 반대로 독성이
생기면 연장치료나 넓은 방사선 선택을 제한한다. 이것이 동적 환경이다.

---

## 선택지는 얼마나 늘었나

| 결정 지점 | 선택지 |
|---|---|
| 치료 순서 | 수술 먼저 / 선행치료 |
| 수술 | BCS / MAST |
| 항암 | 없음 / 표준 / 강화 |
| 호르몬 | 없음 / 표준 / 연장 |
| 방사선 | 없음 / 국소 / 광범위 |
| 치료 반응 | 큰 반응 / 부분 반응 / 없음 |
| 매년 결과 | 무사건 / 재발 / 사망 |

환자별 치료·반응 의사결정 궤적은 **18개에서 135개**다. 여기에는 5년 동안
매년 갈라지는 무사건·재발·사망 경로를 아직 세지 않았으므로 실제 simulation
경로는 더 많다.

모든 선택지를 아무에게나 허용하지는 않았다.

- HR 음성 환자는 호르몬치료를 선택할 수 없다.
- 종양이 크거나 병기가 높으면 BCS를 제한한다.
- 선행치료가 맞지 않는 저위험 상태는 수술 우선만 허용한다.
- 독성이 생기면 부담이 큰 일부 연장·광범위 행동을 제한한다.

---

## METABRIC이 알려 준 것과 우리가 가정한 것

이 구분이 이번 작업에서 가장 중요하다.

### METABRIC에서 배운 것

- 어떤 환자가 5년 안에 사망할 위험
- 어떤 환자가 5년 안에 재발 또는 사망할 위험
- 나이, 병기, 종양 크기, 림프절, 분자아형과 위험의 관계
- 실제 치료와 결과 사이의 관찰 연관성

OS 모형은 1,955명, RFS 모형은 1,951명으로 학습했다. 보류 테스트 C-index는
각각 `0.677`, `0.649`였다.

### 아직 METABRIC이 알려 주지 못한 것

- 표준 항암과 강화 항암의 정확한 차이
- 선행치료 후 큰 반응이 나올 확률
- 치료별 독성 확률
- 국소와 광범위 방사선의 차이
- 환자가 느끼는 삶의 질 가중치

이 값들은 `configs/dynamic_poc_v0_2.json`에 **합성 학습용 가정**으로 따로
적었다. 코드 속에 숨기지 않았고, 나중에 K-CURE 수치로 교체할 자리다.

## MCTS는 이제 어떻게 생각하나

MCTS는 같은 행동을 한 번만 시험하지 않는다.

```text
선행치료를 선택
  -> 이번 simulation에서는 큰 반응
  -> 다음 simulation에서는 부분 반응
  -> 또 다른 simulation에서는 독성 발생
```

이런 가상 실험을 결정마다 256번 반복하고 평균적으로 점수가 높은 행동을 고른다.
실제 반응이 나온 뒤에는 그 상태에서 다시 탐색한다. 즉 처음부터 5년 계획을
고정하는 것이 아니라, 중간 결과를 보고 재계획한다.

---

## 어떻게 시험했나

- 보류 테스트 환자 40명
- HR+/HER2-, HR+/HER2+, HR-/HER2+, TNBC 각 10명
- 환자마다 정책별 100회
- NCCN형 기준 4,000 episode
- 동적 MCTS 4,000 episode
- seed `20260711` 고정

## 결과

| 지표 | NCCN형 기준 | 동적 MCTS |
|---|---:|---:|
| 평균 utility | 0.785 | 0.806 |
| 5년 생존 | 74.2% | 75.4% |
| 5년 내 재발 | 6.8% | 5.2% |
| 평균 독성 사건 | 0.275 | 0.238 |

![동적 정책 결과](/figures/fig15_dynamic_policy_outcomes.png)

이 표를 보고 “MCTS가 생존을 1.2%p 높였다”고 말하면 안 된다. 치료 반응과
독성의 일부는 우리가 만든 합성 가정이고, MCTS는 바로 그 가정의 점수를 높이도록
설계됐기 때문이다. 지금 확인한 것은 **환경과 탐색 파이프라인이 작동한다**는
것이다.

### MCTS가 새 선택지를 실제로 사용했나

| 행동 | NCCN형 기준 | 동적 MCTS |
|---|---:|---:|
| 선행치료 | 0.0% | 20.0% |
| BCS | 90.0% | 59.3% |
| 강화 항암 | 0.0% | 25.0% |
| 연장 호르몬 | 0.0% | 15.2% |
| 광범위 방사선 | 5.5% | 18.7% |

![동적 행동 선택](/figures/fig16_dynamic_action_choices.png)

선택지를 코드에 추가만 한 것이 아니라 MCTS가 환자 상태에 따라 실제로 사용했다.
그러나 어떤 행동이 좋은지는 합성값에 민감하므로 아직 임상 해석 대상이 아니다.

### 탐색은 안정적인가

256회 탐색의 첫 행동은 1,024회 기준과 72.5% 같았다. 기준에서 두 행동의 기대값
차이가 0.01 이하인 사실상 동률까지 포함하면 85.0%다. 정적환경보다 흔들리는
것은 확률 결과가 추가됐기 때문이며, 여러 seed 반복이 다음 과제다.

![동적 탐색 안정성](/figures/fig17_dynamic_search_stability.png)

## K-CURE로 어떻게 이어지나

현재 구조는 레고처럼 세 층으로 나눴다.

```text
1. 데이터 변환기
   METABRIC 또는 K-CURE -> 같은 환자 형식

2. 위험·전이 숫자
   지금: METABRIC + 합성 가정
   미래: K-CURE에서 직접 추정

3. MCTS 환경과 탐색기
   데이터셋이 바뀌어도 그대로 사용
```

K-CURE에서는 치료 시작일, 약제와 용량, 반응평가일, 독성, 재발일, 사망일을
사용해 현재 합성 가정을 실제 한국인 데이터 전이로 바꾸게 된다. 필요한 변수와
이행 순서는 `docs/k-cure-adaptation.md`에 따로 정리했다.
