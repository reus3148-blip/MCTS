## 결정 1 — 1차 임상 데이터셋: METABRIC

### 맥락
연구 로드맵 1단계 INPUT 으로 "치료 입력 → 결과(생존·재발) 관찰" 이 가능한 임상 데이터가 필요하다. 후보를 비교했다.

### 검토한 옵션
| 후보 | 규모 | 접근 | 시간·비용 | 한계 |
|---|---|---|---|---|
| **METABRIC** (cBioPortal) | 2,509명 | 즉시 다운로드 | 0 | 영국 1977-2005 코호트, 신약 시대 이전 |
| TCGA-BRCA (GDC) | ~1,100명 | GDC API | 0 | 임상마커가 METABRIC보다 거침 |
| SEER (NCI) | 수십만 명 | DUA 신청·심사 | 수개월 | 분자마커 한정적 |
| Wisconsin Breast Cancer (UCI) | 569명 | 즉시 | 0 | 진단 분류용, 치료 결과 없음 |
| K-CURE (한국 암 빅데이터) | 수만~수십만 | PI 신청 · 폐쇄망 분석실 | 3-6개월 · 학부생 단독 불가 | 청구자료 베이스라 분자마커 제한 |

### 결정
**METABRIC 선택** (cBioPortal datahub의 Git LFS 미러에서 `data_clinical_patient.txt` / `data_clinical_sample.txt` 다운로드).

### 이유
1. **시간**: 9개월 학부 연구에서 데이터 신청·승인 대기 위험을 제거. 즉시 다운로드.
2. **임상 마커 풍부**: ER · PR · HER2 · PAM50 · 3-gene classifier · NPI · 병기 · grade · 림프절 · 종양크기 모두 포함.
3. **추적기간 20년+**: 호르몬 치료 환자의 late recurrence(10-15년) 까지 관찰 가능 — 최근 RWD 로는 불가능한 장점.
4. **재현성**: 공개 데이터이므로 결과를 외부에서 검증 가능.

### K-CURE 보류 사유
- 학부생 단독 신청 불가 (연구책임자 자격 필요)
- 신청-승인 기간 3-6개월 → 9개월 일정 위험
- 청구자료 베이스라 ER/PR/HER2/PAM50 같은 분자마커는 KCCR 연계로도 제한적
- 장기 카드로는 유효 → 별도 트랙으로 신청 검토 (이번 결정에서는 보류)

## 결정 2 — patients.csv 스키마 (23 컬럼)

### 맥락
원본 두 파일(patient 24열, sample 13열)을 PATIENT_ID 로 join 한 뒤 연구용 표준 컬럼만 추려 `data/processed/patients.csv` 로 저장.

### 결정 — 컬럼 매핑
| 분류 | 컬럼 |
|---|---|
| 식별 | `patient_id` |
| 인구 | `age`, `menopause` |
| 종양 | `tumor_size_mm`, `lymph_pos`, `stage`, `grade`, `histology`, `laterality` |
| 마커 | `er`, `pr`, `her2`, **`subtype`**(파생), `pam50` |
| 치료 | `surgery`, `chemo`, `hormone`, `radio` |
| 결과 | `os_months`, `os_event`, `rfs_months`, `rfs_event`, `npi` |

### 표준화 규칙
- ER 컬럼의 원본 오타 `Positve` → `Positive` 정정
- Positive/Negative → 1/0, YES/NO → 1/0
- OS_STATUS `0:LIVING` / `1:DECEASED` → 0/1 분리
- `subtype` 파생: ER/PR/HER2 조합 → HR+/HER2-, HR+/HER2+, HR-/HER2+, TNBC

### 처리 결과
- 2,509명 × 23 컬럼 저장 완료
- **결측 패턴**: 약 529명(21%)이 임상마커·치료·생존을 일괄 결측 → METABRIC validation cohort 로 추정. 모델링 단계에서 제외 또는 별도 처리 필요.
- 분자아형 분포: HR+/HER2- 1,413(56%) · TNBC 320(13%) · HR-/HER2+ 134(5%) · HR+/HER2+ 113(5%) · 결측 529(21%)
- 병기 분포: 1=630, 2=979, 3=144, 4=11, 0(in situ)=24, 결측 721(29%)

### Ki67 부재 대응
METABRIC 에는 Ki67 측정값이 없다. PAM50 LumA(저증식) vs LumB(고증식) 구분으로 증식 활성도를 대용한다. 본 연구 범위에서 받아들일 수 있는 절충.

## 결정 3 — 치료 시점 정보 부재 대응 (가장 큰 구조적 결정)

### 문제
METABRIC 은 환자가 chemo/hormone/radio/surgery 를 "받았다/안받았다" 의 YES/NO 플래그만 기록한다. **언제·어떤 순서로 받았는지는 없다.** MDP 의 본질인 sequential decision 을 데이터로부터 직접 학습할 수 없다.

### 검토한 옵션
- **A. 순서 정보가 있는 데이터로 교체**
  - SEER-Medicare / Flatiron / 자체 IRB. 시간·비용 부담 큼. 9개월 일정 무리.
- **B. 1-shot 의사결정 문제로 축소**
  - 치료 조합 16가지 중 하나를 한 번에 선택. MDP/RL 의 정당성이 약화됨. "왜 MCTS 인가?" 가 깨짐.
- **C. 환경에 NCCN 표준 시퀀스를 강제, 데이터의 YES/NO 를 결정 노드의 행동 라벨로 해석**
  - 데이터는 (a) 전이확률 추정, (b) 초기 환자 상태 분포 sampling 에만 사용.

### 결정
**옵션 C 채택.**

### 이유
1. 침습성 유방암 치료 시퀀스는 임상에서 사실상 고정되어 있다 — `진단 → 신보조 항암 → 수술 → 보조 항암 → 방사선 → 호르몬 → HER2 표적`.
2. 로드맵 2단계에서 **"환경(시뮬레이터)을 우리가 정의한다"** 고 이미 전제되어 있다. 환경에 순서를 박아넣는 것은 가정이 아니라 설계.
3. 데이터로 transition probability 를 추정하는 데는 시퀀스가 필요 없다 — "이 상태의 환자가 이 행동을 받았을 때 다음 상태의 분포가 어떻게 되는지" 만 알면 된다.

### 6개 결정 노드 (잠정)
1. 신보조 항암 (Y/N)
2. 수술 종류 (Mastectomy / BCS)
3. 보조 항암 (Y/N)
4. 방사선 (Y/N) — BCS 는 사실상 필수
5. 호르몬 (Y/N, 기간 5/7/10년)
6. HER2 표적치료 (Y/N) — HER2+ 환자 한정

### 한계 명시
논문에는 다음과 같이 적는다.
> "데이터셋의 치료 시점 정보 부재로 본 연구는 표준 NCCN 시퀀스를 환경에 강제로 가정한다. 실제 임상 시점 변동성은 본 PoC 의 범위를 벗어나며 후속 sensitivity analysis 의 대상이다."

## 결정 4 — 데이터 시기 mismatch 대응: 연구 frame 재정의

### 문제
METABRIC 진단 시점은 1977-2005년이다. 그 사이 유방암 치료는 본질적으로 바뀌었다.

| 시기 | 도입된 것 | METABRIC 포함? |
|---|---|---|
| 1980s | Tamoxifen | ✅ |
| 1990s | BCT+RT 표준화, Anthracycline-Taxane | 부분적 |
| 2001-2005 | **Trastuzumab** (HER2+) | ❌ 거의 없음 |
| 2010s | PAM50/Oncotype 기반 chemo 결정, Pertuzumab | ❌ |
| 2015~ | **CDK4/6 inhibitor** (Palbo/Ribo/Abema) | ❌ |
| 2020~ | **Pembrolizumab** (TNBC), Olaparib, T-DXd | ❌ |

특히 HER2+ 환자 약 240명이 trastuzumab 을 받지 못한 상태로 추적되었다 — 현재 기준 명백한 substandard treatment. 그대로 "최신 NCCN vs MCTS" 를 비교하면 결과는 인위적이다.

### 검토한 옵션
- ① **연구 frame 을 "검증 PoC"로 재정의** — Komorowski et al. (Nature Medicine 2018, "AI Clinician") 의 sepsis MIMIC-III 연구가 같은 구조.
- ② **시대 무관한 골격 결정만 비교** — HER2 표적치료·CDK4/6i·면역치료는 행동 공간에서 제외.
- ③ 시대-적합 가이드라인(2010년 NCCN) 적용 — 옛 NCCN 원본 확보·검증 부담.
- ④ TCGA-BRCA 추가로 시기 보강 — 임상 변수 정제 추가 작업.

### 결정
**① + ② 조합 채택.**

연구의 자리매김:
> "본 연구는 METABRIC 코호트(1977-2005)에 대해, HER2 표적치료·CDK4/6 inhibitor·면역치료 등 시기 이후 신약을 제외한 핵심 4개 결정 노드(수술 종류·보조 항암·방사선·호르몬)에 한해 NCCN 가이드라인 정책과 MCTS 정책을 시뮬레이션 비교한다. **본 연구는 가이드라인-MCTS 비교 프레임워크의 PoC 이며**, 임상 적용 가능성은 최신 RWD 를 활용한 후속 연구에서 검증되어야 한다."

### 시각 전환 — 옛 데이터의 장점
시기 mismatch 를 단점이 아닌 scope 정의로 다루면 다음이 장점이 된다.
- **추적 기간 20년+** — 호르몬 치료 환자의 late recurrence(10-15년) 까지 관찰. 2010년대 코호트로는 불가.
- **신약 혼재 없음** — 수술·항암·방사선·호르몬의 골격 효과를 깨끗하게 분리 관찰 가능.
- **재발 패턴 풍부** — 골격 치료의 장기 효과 측정에 적합한 코호트.

### 시뮬레이션 환경 설계 원칙
- 환경은 **2010-2015년경 표준 NCCN** 기준으로 정의 (METABRIC 추적 종료 시점과 정합).
- 데이터는 환경의 transition probability 추정과 초기 상태 분포에만 사용.
- 행동 공간에서 시기 이후 신약은 명시적으로 제외 (한계로 논문에 기록).

## 결정 5 — 도메인 mcts.blundermate.app 연결

### 맥락
연구 사이트의 기본 URL `mcts-three.vercel.app` 외에 짧고 기억하기 쉬운 커스텀 도메인 필요.

### 결정
`mcts.blundermate.app` 서브도메인을 Vercel 프로젝트(`mcts`)에 추가.

### 절차
1. `blundermate.app` 은 Vercel Domains 로 관리 중 → DNS 자동 처리.
2. CLI: `vercel domains add mcts.blundermate.app mcts`
3. SSL 자동 발급 완료, ICN1 (인천 엣지) 서빙 확인.

### 결과
- ✅ `https://mcts.blundermate.app` 정상 (HTTP 200, TLS OK)
- ✅ 기존 `mcts-three.vercel.app` 도 유지 — 두 도메인 모두 같은 배포를 가리킴
- ✅ 이후 `git push` 시 자동 배포에서 양쪽 모두 갱신
